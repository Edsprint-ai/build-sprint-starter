## Rules

- **Read the licence before you copy any code.** Reading a repository to
  understand it is always fine. Copying from it is not always fine.
- **AGPL and GPL code may be studied, not copied** into this project. Your
  brief may name an AGPL reference for exactly this reason.
- **Some datasets are research-use only.** Those are referenced and downloaded
  by a script, never committed to an MIT repository.
- Original code written by squad members is **MIT**, so every member can use it
  in a portfolio.
